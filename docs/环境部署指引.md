# 环境部署指引（T0.1 – T0.3）

目标：在 4C8G Linux 服务器上跑起 AgentTeams，浏览器打开 Element Web 并能与 Manager 对话。
全程约 40 分钟。以下以阿里云 ECS + 阿里云百炼为例。

## T0.1 服务器 + Docker（约 20 分钟）

### 1. 创建 ECS 实例

- 规格：**4 vCPU 8 GiB**（最低 2C4G，多 Worker 建议 4C8G）
- 镜像：**Ubuntu 22.04 LTS 64 位**（AgentTeams 在云虚拟机上只支持 Linux，不支持 Windows 镜像）
- 系统盘：≥40 GB；分配公网 IP；按量付费即可（赛后可停机/释放）

### 2. 安全组

只放行 **22 端口（SSH）**，并建议限源 IP 为本机公网 IP。
**不要**对公网开放 18080 / 18088 / 13000 等端口——一律走 SSH 隧道访问（见 T0.3 第 4 步），这也是我们方案「安全可审计」故事的一部分。

### 3. 安装 Docker

```bash
ssh root@<ECS公网IP>
curl -fsSL https://get.docker.com | bash
systemctl enable --now docker
docker version && docker compose version
```

两条命令都输出版本号即成功。

## T0.2 百炼 API Key（约 5 分钟）

1. 打开百炼控制台 <https://bailian.console.aliyun.com>，首次使用先开通服务（开通免费，按 token 计费，新账号有免费额度）。
2. 进入 **密钥管理（API-KEY）→ 创建新的 API Key**，复制 `sk-xxxxxxxx` 妥善保存（只完整显示一次）。
3.（可选）验证 Key 可用：

```bash
curl https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"model":"qwen-plus","messages":[{"role":"user","content":"你好"}]}'
```

返回正常回复即 Key 可用。手动配置时需要的信息：Base URL `https://dashscope.aliyuncs.com/compatible-mode/v1` + API Key + 模型名。

## T0.3 安装 AgentTeams（约 15 分钟）

### 1. 一键安装

```bash
bash <(curl -sSL https://raw.githubusercontent.com/agentscope-ai/AgentTeams/main/install/agentteams-install.sh)
```

### 2. 向导选择

| 步骤 | 选择 |
| --- | --- |
| 语言 | 中文 |
| 安装模式 | 快速开始（阿里云百炼快速安装） |
| API Key | 粘贴 T0.2 的 `sk-xxxxxxxx` |
| 默认模型 | 直接回车用默认（当前默认 qwen3.6-plus） |
| 网络模式 | 本地访问（local-only，配 SSH 隧道；复赛演示需要外部访问时可重装切换） |
| GitHub 集成 / Skills 注册中心 / 数据持久化 / 工作空间 | 全部回车默认 |
| Manager / Worker 运行时 | OpenClaw（默认） |

### 3. 保存登录信息

安装结束会打印 **自动生成的 admin 密码**——立即复制保存（用户名 `admin`）。
安装日志在 `~/agentteams-install.log`，出错先看它。

### 4. 本机访问（SSH 隧道）

在你自己电脑的终端执行并保持窗口开启：

```bash
ssh -L 18088:127.0.0.1:18088 -L 13000:127.0.0.1:13000 root@<ECS公网IP>
```

浏览器打开 <http://127.0.0.1:18088>，用 `admin` + 密码登录 Element Web，Manager 会在房间里主动打招呼。13000 是 Dashboard 管理界面。

## 验收标准

1. `docker ps` 能看到 agentteams-manager、higress、tuwunel（Matrix）、minio、element-web、dashboard 等容器全部 Up；
2. Element 登录后收到 Manager 的欢迎消息，并能让它创建一个测试 Worker。

两项都通过后回报截图，环境即就绪，可直接进入 WP1/WP3 联调。

## 常用运维命令

```bash
# 查看 Manager 日志
docker exec -it agentteams-manager cat /var/log/agentteams/manager-agent.log
# 升级（保留数据）：重新运行安装脚本即可
bash <(curl -sSL https://raw.githubusercontent.com/agentscope-ai/AgentTeams/main/install/agentteams-install.sh)
# 完全卸载
bash <(curl -sSL https://raw.githubusercontent.com/agentscope-ai/AgentTeams/main/install/agentteams-install.sh) uninstall
```
