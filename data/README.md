## 场景 A 关键时间线

车辆 VIN `LSVA0000DEMO00001`，7kW 交流慢充，累计里程 23456 km，环境温度 32℃。

| 时刻 | 事件 |
| --- | --- |
| 09:00–09:30 | 正常基线：OBC 输出 ≈398V / 16.6A（≈6.6kW），SOC 55% → 61% |
| 09:30:00–09:31:27 | 故障注入：`obc_output_voltage` 由 398V 爬升至 442V |
| 09:31:27 | 越限（≥440V），`alarm_level = 1` |
| 09:31:32 | 越限持续 5s，DTC **P3509** 确认，`alarm_level = 2`，冻结帧落盘 |
| 09:32–09:34 | 充电降流保护：16.6A → 8A |
| 09:35:00 | 充电保护停机；OBC 输出电压读数**卡滞在 442V** |

## 诊断要点（真值）

注入故障为 **OBC 输出电压传感器漂移**，而非真实过压：

- `pack_voltage` 全程 398V 正常，与 `obc_output_voltage`（442V）背离 >40V；
- 停机后输出电压读数仍保持 442V（传感器卡滞特征）；
- `obc_temperature` 仅轻度上升，无真实过压应有的过功率热特征。

期望结论：OBC 输出电压传感器 / 采样回路故障；期望处置：L1 清码复检（自动放行 + 留痕）+ 生成处置建议单（进站检修 OBC）。这构成 W3 诊断推理 Agent 交叉验证能力的主评估用例。

## 场景 B 关键时间线

车辆 VIN `LSVA0000DEMO00002`，120kW 直流快充，累计里程 18920 km，环境温度 35℃。

| 时刻 | 事件 |
| --- | --- |
| 14:00–14:10 | 正常快充：-110A 恒流，SOC 55% → 68%，`cell_temp_max` 34℃ → 38℃（0.4℃/min 温和上升） |
| 14:10–14:18 | 电流渐收至 -95A，SOC → 74%；温度加速爬升 38℃ → 55℃ |
| 14:18:00 | `cell_temp_max` 首个 ≥55℃ 样本，`alarm_level = 1`，BMS 降流至 -60A |
| 14:18–14:23 | **降流后温升率不降反升**（2.1 → 2.95℃/min），pack 电压缓降、绝缘电阻加速下降 |
| 14:23:05 | `cell_temp_max` 首个 ≥70℃ 样本，`alarm_level = 2`；pack ≈398V，绝缘 ≈1800kΩ |
| 14:25:12 | `cell_temp_max` 首个 ≥80℃ 样本（82.6℃），`alarm_level = 3`，DTC **BMS-TH01** 确认并断充（电流归零），冻结帧落盘 |
| 14:25:12–14:29:59 | **断充后零电流温升不止**：82.6℃ → 89.3℃；绝缘降至 ≈1200kΩ，pack 缓降至 ≈394V |

## 场景 B 诊断要点（真值）

注入故障为**单体电芯内部短路导致的热失控前驱**（真实热事件），而非温度传感器故障：

- **多信号互证**：温度 / pack 电压 / 绝缘电阻三条独立通道同向恶化——对比场景 A 的背离逻辑，单传感器故障时其余通道应保持正常；
- **降流后温升率不降反升**：14:18 降流至 -60A 后温升率仍由约 2.1℃/min 升至约 2.95℃/min，说明热源在电池内部而非充电电流；
- **断充后零电流温度继续上升**：内部自发热铁证；
- **绝缘电阻持续下降 + pack 电压缓降**：隔膜失效 / 泄漏前兆。

期望结论：真实热失控前驱（置信度 >0.8，need_human_review=true，检索引用 CASE-0005）；期望处置：L2 `remote_charge_inhibit` 远程禁止充电 + 通知车主立即停车避险——仅创建审批单，人工审批后执行，禁止自动执行；禁忌：对热事件车辆 `clear_dtc` 掩盖报警。
